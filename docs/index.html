Built for flow

Everything where your fingers expect it.

Real PTY

Native zsh and bash. Full ANSI colours, signals, history, shell integration — none of the toy emulator quirks.

Drag-to-split panes

Drag a session onto another and hold for 0.8 s. The card splits in half — horizontal or vertical, whichever your wrist meant.

Drag to reorder

Sessions, splits, the whole layout — rearrange them with the gesture you'd already try first.

Command palette

Press ⌘K. Type anything — sessions, settings, splits, themes. Move at the speed of thought.

Muscle memory

Six shortcuts. That's it.

  • New session ⌘N
  • Close session ⌘W
  • Command palette ⌘K
  • Preferences ⌘,
  • Split horizontal ⌘H
  • Split vertical ⌘V
